Preview states

The wallet card stays at the top. The withdrawal status widget only appears when there is an active withdrawal state. Completed withdrawals should move to Recent Activity instead of staying on Home.

Implementation logic

  1. Read the latest active withdrawal for this partner.
  2. If status is requested/pending, show pending widget.
  3. If status is payment sent, show confirmation widget.
  4. If status is completed, hide widget and show in activity.
  5. If active campaign exists, show campaign after withdrawal state.
